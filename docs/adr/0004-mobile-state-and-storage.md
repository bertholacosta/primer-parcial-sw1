# ADR-0004: estado y almacenamiento del runtime móvil

- Estado: `proposed`
- Decisor: Product Owner

## Pregunta

¿Qué estrategia de estado, persistencia local, migración y cola offline usará Flutter en Android?

## Evidencia requerida

Compatibilidad con descriptor versionado, pruebas sin red, migraciones reproducibles y límites claros entre UI dinámica y persistencia.

## No decisión

No se selecciona librería en Fase 0. `P3-002` debe comparar opciones y registrar la aprobación.
