# ADR-0001: tecnología del editor CASE web

- Estado: `proposed`
- Decisor: Product Owner

## Pregunta

¿Qué stack y biblioteca de edición gráfica satisfacen el modelado UML, rendimiento, accesibilidad, pruebas y mantenimiento del proyecto?

## Evidencia requerida

- Matriz breve de alternativas compatibles con las restricciones del repositorio.
- Prototipo o prueba técnica acotada para los riesgos principales.
- Estrategia de comandos que preserve al modelo canónico como fuente de verdad.
